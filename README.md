# 은빛산 포켓몬 배틀 · 6 vs 6

**플레이:** https://pokemon-arena-rosy.vercel.app · **저장소:** [songyh1996/pokemon-arena](https://github.com/songyh1996/pokemon-arena) (private)

Vercel Hobby의 정적 배포입니다. `main` 브랜치에 푸시하면 자동으로 다시 배포됩니다. 게임 URL은 공개 접근 가능하며, 저장소만 비공개입니다.

1·2세대 인기 포켓몬 **50마리**, 각 팀 **6마리**로 즐기는 실시간 로컬 팬 게임입니다. 한 번에 양쪽 한 마리씩 싸우며, **P**로 파트너를 교체합니다. Pokémon Battlegrounds의 *RED vs GOLD*에서 영감을 받았습니다.

## 실행

Node.js 20 이상. 외부 패키지 설치 없이 `npm start` 후 **http://localhost:5173** 에 접속합니다. 서버는 127.0.0.1에만 바인딩됩니다. 다른 포트는 `PORT=5174 npm start`.

## 정적 빌드와 Vercel

- `npm run build`: 외부 빌드 의존성 없이 `dist/`에 게임을 생성합니다. `public/assets`는 배포 시 `/assets`에서 제공됩니다.
- `npm run preview`: 완성된 정적 빌드를 **http://localhost:5174** 에서 확인합니다.
- Vercel: Framework **Other**, Build Command **npm run build**, Output Directory **dist**. `vercel.json`에 설정되어 있으며 별도 서버/환경 변수는 필요하지 않습니다.
- GitHub 저장소는 private로 유지합니다. `dist`, `node_modules`, `.vercel`, 환경 변수 파일과 개인 키는 Git에서 제외합니다.
- 배포 결과에는 게임의 브라우저 코드와 에셋만 포함합니다. 저장소 관리 파일·테스트·서버·인증 정보는 포함하지 않습니다.
- 검색 노출을 줄이기 위해 `robots.txt`와 `X-Robots-Tag: noindex, nofollow`를 제공합니다. **검색 차단이나 private GitHub 저장소는 배포 URL의 접근 제어가 아닙니다.** 비공개 접속이 필요하면 Vercel 배포 보호를 별도로 설정해야 합니다.

## 파티 편성

- 새로 열 때 내 파티는 항상 **0/6**입니다. 포켓몬 초상화를 누르면 다음 빈자리에 자동으로 추가됩니다. 슬롯을 먼저 고를 필요가 없습니다.
- 선택한 포켓몬이나 채워진 슬롯을 다시 누르면 제외됩니다. 다음 선택은 생긴 빈자리를 채웁니다. 같은 팀은 중복 불가이며 여섯 마리가 완성되어야 시작할 수 있습니다.
- 상대는 기본 **AUTO**입니다. 시작할 때 여섯 마리를 무작위로 편성합니다. 원하면 상대도 직접 고를 수 있습니다.
- 최근에 직접 고른 파티는 **최근 파티**를 눌렀을 때만 불러옵니다. 이전 자동 기본 파티는 복원하지 않습니다. 랜덤 채우기와 비우기도 명시적인 버튼으로 제공합니다.
- 포켓몬 선택 시 실제 울음소리가 재생됩니다. 검색과 타입 아이콘 필터, 여섯 개의 트레이너 기술 아이콘과 5단계 난이도를 제공합니다. 드롭다운으로 기술을 고르지 않습니다.
- 출전할 두 파티의 실제 스프라이트를 준비한 다음 배틀이 시작됩니다. 난이도·트레이너 기술·소리/효과 설정은 유지됩니다.

## 조작

- **방향키:** 이동. 대각선 속도를 정규화합니다.
- **평타:** 항상 자동. 사거리 안에 상대를 두면 이동 중에도 공격하며, 평타 준비가 이동을 느리게 하지 않습니다. A/Space/T나 공격 토글은 없습니다.
- **Q / W / E:** 현재 포켓몬의 고유 기술. 이동만 하는 순간이동은 없으며, 공격 돌진은 피해를 주는 기술입니다.
- **R:** 가장 강한 기술. 최초 30초 충전, 사용 후 60~70초 재사용 대기. 대기 포켓몬도 같은 전투 시간으로 충전됩니다.
- **S:** 선택한 트레이너 기술. 고정 점멸은 제거했습니다.
- **D:** 방향성 회피. 즉시 0.5초 무적, 2초 재사용, 175 거리/0.28초 이동. 경직 중에도 사용 가능하며 방향키가 없으면 상대 반대편으로 회피합니다. 적 유도탄과 발사 전 추적 공격의 조준을 끊습니다. 탄을 삭제하지 않으므로 이후 직선 궤도로 돌아가면 맞을 수 있습니다. 체력 회복이나 화상 정화는 하지 않습니다.
- **P:** 교체할 포켓몬 선택. 방향키/Enter 또는 클릭으로 결정, P/Esc로 취소합니다.
- **Esc:** 메뉴/재개. **M:** 소리. **H:** 현재 포켓몬 기술 설명.

물리 키 위치로 입력을 처리하므로 한글 IME 상태에서도 QWER/S/D/P를 사용할 수 있습니다. 키보드와 클릭, 터치 이동 패드를 지원합니다. 다른 탭으로 이동하면 전투가 자동 정지됩니다.

## 트레이너 기술

- **가속 / Ghost:** 4초 동안 이동 속도 +50%. 재사용 18초.
- **위압 / Exhaust:** 사거리 450, 3초 둔화와 주는 피해 35% 감소. 재사용 20초.
- **배리어 / Barrier:** 최대 HP 20% 보호막, 3초 지속. 재사용 22초.
- **회복 / Heal:** 현재 포켓몬의 최대 HP 16% 회복. 초과 회복/부활 없음. 재사용 26초.
- **정화 / Cleanse:** 경직·둔화·화상·위압·점화 제거 및 3초 상태 이상 방어. 피해 자체를 막는 무적은 아닙니다. 재사용 16초.
- **점화 / Ignite:** 사거리 430, 4초 동안 총 144의 지속 피해. 회피/보호막으로 피해를 줄일 수 있습니다. 재사용 20초.

S와 D 재사용 시간은 팀 전체가 공유합니다. 포켓몬 교체로 재사용 시간을 초기화할 수 없습니다. 트레이너 기술은 MP를 쓰지 않습니다.

## 난이도

난이도는 **입문 → 쉬움 → 도전 → 챔피언 → 마스터**의 5단계입니다. 선택값은 파티와 함께 브라우저에 저장되며, 기존 저장과 회귀 테스트를 위해 `standard`(도전)와 `expert`(챔피언) ID 및 수치는 그대로 유지합니다. 차이는 주로 공격 예고와 후딜, 탄속·유도·이동 예측, 일반 기술 사용 주기에서 나며 피해 배율은 0.90~1.18로 제한합니다.

도전의 장판/궁극기 공격 예고는 각각 0.95초/1.10초로 0.9초 이상을 유지합니다. 수비형 기술의 짧은 0.2초 상태 표시는 모든 난이도에서 동일합니다.

## 교체와 기절

- 양쪽에 한 마리만 출전합니다. 여섯 마리가 동시에 싸우지 않습니다.
- 수동 교체에는 8초 재사용 시간이 있으며, 메뉴를 선택하는 동안 전투가 멈춥니다.
- 각 포켓몬의 HP, MP, QWER 쿨타임을 유지합니다. 대기 중에도 기술 쿨타임/상태 지속 시간이 감소하고 MP가 회복되지만, 대기 포켓몬에게 화면 밖 지속 피해를 주지는 않습니다.
- 교체 위치는 유지되며 새 체격에 맞춰 경계를 보정합니다. 출전 직후 0.6초 보호를 제공합니다.
- 물러난 포켓몬의 준비 중 공격과 투사체/장판은 취소됩니다. **상대가 발사한 공격은 지우지 않습니다.**
- 내 포켓몬이 기절하면 살아 있는 대기 포켓몬을 반드시 선택합니다. 이 선택은 취소할 수 없고 수동 교체 쿨타임에 막히지 않습니다.
- 상대는 기절 후 다음 살아 있는 포켓몬을 약 1초 뒤 내보냅니다. 한 팀의 여섯 마리가 모두 기절해야 승패가 결정됩니다.

## 전투와 화면

- 적은 예고 → 공격/투사체 이동 → 후딜 순서로 행동하며, 한 행동 중 다른 공격을 겹치지 않습니다.
- 고정 조준선, 범위 예고, 초록색 반격 기회, D 유도 해제와 실제 회피 피드백을 표시합니다.
- 5단계 난도가 올라가면 공격 예고와 후딜이 짧아지고 탄속·유도·예측·기술 연계가 강해집니다. 피해량 변화는 보조적인 수준으로 제한합니다.
- 포켓몬 RPG풍 도감, 여섯 슬롯의 파티, HP 바와 몬스터볼 잔여 표시, 기술 메뉴, 교체/기절/승패 화면을 사용합니다.
- 실제 방향별 PMD 스프라이트, 타격 시점에 맞춘 애니메이션, 반동/히트스톱, HGSS 챔피언 음악을 유지했습니다.
- 원본에 Faint가 없는 34종은 매니페스트에 명시한 실제 Hurt 애니메이션을 대체 사용합니다. 토게피의 Shoot는 실제 Attack 시트로 대체합니다. 원본에 없는 그림을 생성한 것은 아닙니다.

## 타격감과 소리

- 기술의 속성과 형태에 맞춘 준비·발사·명중 소리가 각각 재생됩니다. 기본 공격, 회피, 회피 성공, 여섯 트레이너 기술, 궁극기, 교체에도 별도 피드백을 사용합니다.
- 불꽃·물·전기·얼음·에스퍼·물리 공격 등의 궤적과 명중 이펙트를 구분하며, 방향성 카메라 흔들림과 반동을 적용합니다. 주황색 공격 예고와 초록색 반격 표시는 이펙트 위에 유지합니다.
- 음악과 효과음 볼륨은 독립적으로 조절됩니다. 캐릭터 선택 시 실제 포켓몬 울음소리를 사용하고, 반복 선택 시 이전 소리를 짧게 감쇠합니다.
- 화면 흔들림은 조절 가능하며 시스템의 모션 줄이기를 존중합니다. 하드웨어 진동은 브라우저 진동 API 또는 연결된 게임패드가 지원할 때만 동작합니다. 일반 데스크톱에 진동 장치를 만들어 주지는 않습니다.
- 효과·입자 개수와 진동 패턴은 제한됩니다. 테스트가 보장하는 것은 이벤트/안전 처리이며, 실제 기기의 진동 여부는 하드웨어에 따라 다릅니다.

## 테스트 및 구조

현재 **120개 테스트**가 통과합니다. `test/master-ai.test.js`는 이전 마스터 AI/수치와 동일한 결정론적 이동·회피·기술 사용을 비교하고, 반응 지연·실제 회피 재사용 시간·공격 확정·위험 지역 회피·50종 안정성을 검증합니다.

`npm test`는 자동 평타·이동·회피·유도 해제·5단계 난이도의 예고/후딜·기술/트레이너 효과·파티 교체·팀 쿨타임·기절·완전한 여섯 번 KO 진행·초기화·일시 정지·50종 리소스를 검증합니다. 전체 **2,500 조합**을 32초씩 결정론적으로 시뮬레이션해 NaN/예외/경계 이탈/종료 후 피해도 확인합니다. 테스트는 완벽한 밸런스를 보장하지는 않습니다.
