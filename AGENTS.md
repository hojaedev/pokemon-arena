# Product defaults

- The game is **포켓몬 아레나** (Pokémon Arena). Do not invent a different title or append promotional slogans.
- **Humans don't read.** Make controls understandable by looking, not by reading instructions. Show arrow keys in their real keyboard arrangement and map actions to visible keycaps and recognizable graphics.
- Pokémon art, selection state, health/energy, attack warnings, cooldowns, and actionable controls come first. Remove duplicate labels, bilingual repetition, decorative headings, and default paragraphs.
- Use short Korean labels when they clarify an icon. Do not replace clear labels with obscure symbols. Keep accessible names, keyboard focus, touch targets, and reduced-motion support.
- Put full move descriptions, advanced opponent customization, and long credits behind intentional details/disclosures, while keeping the main actions visible.
- Preserve existing saved settings when renaming UI. The `mt-silver-*` storage keys are legacy compatibility keys, not visible branding.
- Keep the GitHub repository private and publish only the isolated `dist/` build.
- Mobile battles are a two-thumb interface, not a scaled-down keyboard UI: large draggable movement on the lower left, immediate-touch skills on the right, independent multitouch, safe-area-aware portrait/landscape layouts, and no page scrolling during battle. Do not duplicate keyboard diagrams on the phone HUD.
